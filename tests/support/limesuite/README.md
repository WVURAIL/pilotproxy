LimeSuite test headers
======================

Unmodified public headers from LimeSuite v23.11.0, pinned in sources.json.
They provide the API declarations for compiling the capture workers against
the test-defined fake library. No LimeSuite runtime or radio hardware is used.

The upstream license is retained in COPYING. Update both headers together
and record their source revision and SHA-256 hashes when changing API versions.
